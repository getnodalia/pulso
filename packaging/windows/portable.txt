Pulso portable mode

While this file sits next to pulso.exe, Pulso keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the PulsoData folder beside it instead of
%APPDATA%\Pulso. Copy the whole folder to move Pulso with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\Pulso unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\Pulso) instead.
If PulsoData can't be written (for example on a read-only drive), Pulso logs a
warning and uses %APPDATA%\Pulso instead.
